# Skills para desarrollo de software

| Skill | Qué hace | Estado |
| --- | --- | --- |
| [`user-story-create`](./user-story-create/SKILL.md) | Crea una historia de usuario en base a una idea o requerimiento; maneja las fases de Refinamiento Funcional (estándar 3C, criterios de aceptación Gherkin) y Refinamiento Técnico (estimación preliminar en story points), con validación INVEST; el resultado se guarda en `software-factory/user-stories/US-NN.md` del proyecto | En desarrollo — inestable, uso bajo propio riesgo |

## Instalación

Para instalar una skill individual, copia su subdirectorio (`skills/<skill-name>/`) a cualquiera de los directorios donde OpenCode descubre skills (global o por proyecto), o usa `npx skills add lalviarez/software-factory-skills` y selecciona solo la que necesites. Detalle en [Instalación](../README.md#instalación) del README raíz.
